# 论MD文档格式

## 二级标题

Markdown 是一种轻量级标记语言，它允许人们使用易读易写的纯文本格式编写文档。接下来是一个表格：

### 1. 表格示例 (三级标题)

| 语法 | 描述 | 难度 |
| :--- | :---: | ---: |
| `Header` | 标题 | 简单 |
| `Table` | 表格 | 中等 |
| `Math` | 数学公式 | 进阶 |

---

### 2. 文本修饰 (四级标题)

在Markdown中，你可以轻松地使用各种文本修饰：
* **粗体文本** (Bold)
* *斜体文本* (Italic)
* ***粗斜体文本*** (Bold Italic)
* ~~删除线文本~~ (Strikethrough)
* <u>下划线文本</u> (使用HTML标签)

### 4. 引用与嵌套

> 这是一个块引用。
> Markdown 让写作回归纯粹。
>> 这是一个嵌套的块引用。
>> 甚至可以在引用中使用**粗体**或者列表：
>> - 列表项 1
>> - 列表项 2

---

### 5. 代码与代码块

如果你是一个程序员，你可以使用行内代码，比如 `console.log("Hello World");`。

或者使用多行代码块（支持语法高亮）：

```python
def greet(name):
    """
    这是一个Python函数示例
    """
    print(f"Hello, {name}!")
    
greet("Markdown")
```

### 7. 数学公式 (LaTeX)

Markdown 通常支持 LaTeX 数学公式（具体取决于渲染引擎）。

**行内公式：**
爱因斯坦的质能方程是 \(E = mc^2\)，这是一个非常著名的物理公式。

**块级公式：**
下面是一元二次方程的求根公式：

$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$
